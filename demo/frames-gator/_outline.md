## 基本信息

- **主题**：把一位 A 股博主四年复盘做成 AI 可用规则笔记
- **平台**：B 站（科普向 + 开源项目）
- **成片时长**：133.7s
- **核心诉求**：让观众知道有这东西、且**没回测所以别当真**、知道去哪拿

## 逐帧大纲

### p1 · 封面：一句话说清 + 开口就认怂
- 讲：711 篇文章 + 79 场直播 = 48 章规则笔记，全流程无手写
- 画面：三个大数字卡（711 / 79 / 48）
- 口播核心：**"这个项目没有做过回测，规则准不准是未知的"放在第一句**
- ⚠️ 必须：认怂放最前，不藏到片尾。观众第一反应是"准不准"，先答了后面才看得进去
- 16.0s

### p2 · 为什么要做这件事
- 讲：他的判断有效但散落在流水里，自己也说"凭感觉"
- 画面：引言块 + 三个下坠点（有效 / 不成体系 / 无法复用）
- 16.1s

### p3 · 不是摘抄，是翻译
- 讲：把"量能不足要谨慎"翻成 IF-THEN 条件
- 画面：左右两栏对照 + 中间箭头，右栏用等宽字体
- 口播核心：口语 → 结构化的具体例子
- ⚠️ **底部常驻警示条**："这是能写成代码，不是验证有效"——这帧最容易让人误以为已验证
- 16.8s

### p4 · 全流程没手写环节
- 讲：六环节链路 + 每环节用什么技术
- 画面：横向 5 节点链路图 + 下方 2 列 8 行技术表
- 口播核心：**技术栈集中在这里报**（对应简介技术栈段）
- ⚠️ 风险：表格 8 行 + 链路 5 节点，两个都可能溢出 → 渲染前必须抽帧验
- 13.5s

### p5 · 必须专门讲：这个项目没有做过回测
- 讲：仓库里对齐数字是 AI 跑的，没验证没复核，不能证明有效
- 画面：警示横幅 + 三条否定（不能证明有效 / 别引用数字 / 准不准是未知数）
- ⚠️ **全片信任建设核心帧**，单独一屏不给别的内容
- 17.7s

### p6 · 方法本身的固有缺陷
- 讲：2024 年 1–7 月素材空白 + AI 整理必然出错
- 画面：素材缺口块 + 三条风险（曲解原意 / 过度归纳 / 凭空推断）+ 底部"以原文为准"
- ⚠️ **不能因为怕负面就删这帧**，这是主动认怂换取信任的落点
- 19.0s

### p7 · 怎么用：别自己复制，把仓库丢给你的 AI
- 讲：提示词 4744 字手工复制不现实，主推发链接让 AI 自己装
- 画面：主推卡（可复制话术深色框）+ 三张方式卡（发链接 / 存助手设定 / 装技能）
- 口播核心：**"别自己复制四千多字的提示词"——主动打掉观众第一反应**
- ⚠️ 帧长超 12s 是有意为之（信息完整性优先），用 RATE=+22% 补偿
- 19.9s

### p8 · 这是笔记，不是答案
- 讲：定位为检查清单而非买卖建议 + 三种参与方式 + 免责声明
- 画面：三张参与卡 + 版权免责块
- 16.5s

## 汇总

8 帧 · 133.7s。最长 p7 19.9s（操作类内容有意保留），最短 p4 13.5s。

## 风险与敏感表述

**禁用词**：实测 / 验证 / 有效 / 准确率 / 胜率 / 可执行 / 能用

**必须主动讲清**：
1. 没有回测（p1 + p5 各说一次）
2. 对齐数字是 AI 跑的、没人复核
3. AI 整理可能曲解原意，以原文为准
4. 著作权归原作者，仓库仅为整理

**合规**：每帧右上角 AI 角标 + 发布页勾选"使用 AI 合成技术" + 财经类必加免责
